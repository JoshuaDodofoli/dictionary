# Dictionary App

Just a small web application built with Astro and React that allows users to search for word definitions, pronunciations, meanings, and synonyms using the Free Dictionary API.

## Features

- 🔍 **Search Functionality** - Search for any word using the Free Dictionary API
- 🔊 **Audio Pronunciation** - Listen to word pronunciations with Howler.js
- 📖 **Definitions & Meanings** - View multiple meanings and definitions for each word
- 🎯 **Synonyms** - Discover related words and synonyms
- ✨ **Smooth Animations** - Beautiful transitions and animations using Framer Motion
- 📱 **Responsive Design** - Works seamlessly on mobile and desktop devices

## 🌐 API

This app uses the [Free Dictionary API](https://dictionaryapi.dev/) for word data. No API key required!
